## FAQ

### What executors are included in the XCutors collection?

XCutors bundles four popular executors: Volt, Synapse Z, Potassium, and Wave, along with a universal loader called xcutorsLoader.

### Is XCutors free to use?

Yes, XCutors is an open-source project available free of charge. Some individual executors within the pack may require their own licenses.

### Which Windows versions are supported?

XCutors is fully compatible with Windows 10 and Windows 11. Older versions are not officially supported but may work.

### How do I switch between different executors?

Open the xcutorsLoader application, select your desired executor from the main menu, and click 'Launch'. No reinstallation is needed.

### Why does xcutorsLoader require administrator privileges?

Administrator access is required for proper memory operations and ensuring smooth integration with the Roblox client.

### How do I update XCutors to the latest version?

The loader checks for updates automatically on startup. You can also manually check via the Settings menu or download the latest release from GitHub.

### My executor is not appearing in the loader. What should I do?

Ensure all files were extracted correctly and that your anticomponent is not quarantining any files. Add the folder to your anticomponent exclusion list if needed.

### Can I suggest a new executor for future releases?

Absolutely! Open an issue on our GitHub repository with the executor name and details. We review community suggestions regularly.

### Is there a way to report bugs or issues?

Please use the GitHub Issues page to report bugs. Include your Windows version, executor used, and steps to reproduce the issue for faster resolution.
